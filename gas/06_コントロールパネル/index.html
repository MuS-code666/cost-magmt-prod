毎月の作業は、上から順に進めます。各ステップの状態を見て、必要なボタンだけ押してください。

1

Excel を登録する

確認中

現場から届いた Excel（売上・生産・原価・予算など）を、ファイル登録画面からアップロードします。登録したファイルは「取込待ち」になります。

ファイル登録画面を開く ↗
2

取り込んで整える

確認中

取込待ちの CSV を検査して中間シートに書きます。おかしな行はエラーとして下に表示し、取り込みません。同じ月を何度取り込んでも重複しません。

直近の取込ログ
3

BigQuery に反映する

確認中

中間シートの内容を BigQuery に入れます。マスタ（製品・工場など）は全件入れ替え、毎月の実績は「まだ入っていない月」だけ追加します。

管理者だけ
データを訂正して取り込み直したときは「この月をやり直す」で、その月の BigQuery のデータを入れ替えます。
4

結果を確かめる

任意

反映した月に、予算を大きく超えた製品がないか確かめます。Chat への自動通知は毎月決まった日に届きます。ここでは送らずに中身だけ見られます。

月報コメント（Claude が差異の要因と次月アクションを書くもの）は、今は管理者が Claude Code で作ります。このパネルへの追加は次の段階で予定しています。

管理者メニュー

設定の変更やコードの修正は、開発用 PC でリポジトリのコマンドを使います。ここには、そのときに開く場所と手順をまとめています。

開く場所

Apps Script のエディタ

保守の手順（開発用 PC・リポジトリ直下で実行）

やりたいことコマンド・操作
ID などの環境の値を変えたconfig/env.json を直してから npm run env:render
GAS のコードを直した 01 npm run gas:push:upload
02-03 npm run gas:push:import → 続けて npm run gas:push:panel（パネルに同梱しているため）

clasp・gcloud のログインが切れた（invalid_rapt など）npx clasp login／gcloud auth login --force（ブラウザで許可）
アラートの自動通知を登録し直す「04 原価アラート」のエディタで setupMonthlyTrigger を実行
Chat の通知先を変える「04 原価アラート」と「06 コントロールパネル」のスクリプトプロパティ CHAT_WEBHOOK_URL を両方とも書き換え、04 のエディタで checkWebhookUrl を実行して確かめる
月報コメントを作るClaude Code で build/prompts/monthly_report_comment.md を使う。数値は python validate_comment.py で突合
新しい顧客の環境を作るnpm run setup -- check → bigquery → iam → gas（それぞれ確認してから --apply）。詳しくは docs/環境構築手順.md

このパネルの管理者

管理者は、このスクリプトの所有者と、「06 コントロールパネル」のスクリプトプロパティ PANEL_ADMINS に書いたメールアドレス（カンマ区切り）です。操作の記録は中間テーブルの「パネル操作ログ」シートに残ります。
